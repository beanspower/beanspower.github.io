# AIGC 主题介绍

## 什么是 AIGC？

AIGC（AI-Generated Content，人工智能生成内容）是指利用人工智能技术自动生成文本、图像、音频、视频、代码等内容的新型生产方式。与传统 PGC（专业生产内容）和 UGC（用户生产内容）不同，AIGC 代表着内容生产的第三次革命。

## AIGC 的核心能力

### 1. 文本生成

- 对话问答、文章写作、摘要提取
- 翻译、改写、风格迁移
- 代表产品：ChatGPT、Claude、文心一言、GLM

### 2. 图像生成

- 文生图、图生图、图像编辑
- 风格迁移、超分辨率
- 代表产品：Midjourney、DALL·E、Stable Diffusion

### 3. 代码生成

- 代码补全、代码解释、Bug 修复
- 单元测试生成、代码重构
- 代表产品：GitHub Copilot、Claude Code、Cursor

### 4. 音频与视频

- 语音合成、音乐生成
- 视频生成、数字人
- 代表产品：Suno、Sora、ElevenLabs

## 本主题将涵盖的内容

本主题聚焦于 **AI 工具实践与效率提升**，主要分享：

- **OpenClaw** — 开源 AI 助手框架，支持多平台接入与技能扩展
- **Claude Code** — Anthropic 官方编程助手，强大的代码理解与生成能力
- **GLM 系列** — 国产大模型的实践应用
- **工具集成** — MCP、技能系统、自动化工作流
- **最佳实践** — Prompt 技巧、效率提升、避坑指南

## 为什么关注 AIGC？

1. **效率革命**：AI 正在重塑内容创作、编程、办公等领域的生产方式
2. **技术民主化**：开源工具让每个人都能拥有 AI 能力
3. **持续进化**：模型能力快速增长，新工具层出不穷
4. **实践导向**：本主题注重实际使用经验，帮助快速上手
